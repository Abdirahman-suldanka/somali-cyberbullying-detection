# Somali Cyberbullying Detection Using NLP and Deep Learning

## Project Overview

This project focuses on developing machine learning models for detecting cyberbullying in Somali-language text using Natural Language Processing (NLP), deep learning techniques, and Somali language transformer models.

The project aims to address the challenges of identifying cyberbullying in a low-resource language such as Somali, where limited linguistic resources and labeled datasets make automated text classification challenging.

By exploring traditional NLP approaches, deep learning architectures, and transformer-based language models, this project seeks to evaluate different techniques for classifying Somali text and identifying potentially harmful online content.

## Objectives

- Develop text preprocessing and analysis pipelines for Somali-language text.
- Apply NLP techniques to extract meaningful features from Somali text.
- Experiment with deep learning models for cyberbullying detection.
- Explore Somali language transformers for contextual text representation and classification.
- Compare model performance using appropriate evaluation metrics.
- Contribute to research on Somali-language NLP and online safety.

## Technologies

- Python
- Natural Language Processing (NLP)
- Machine Learning
- Deep Learning
- Transformer-based Language Models
- Text Classification
- Model Evaluation and Performance Analysis

## Project Scope

The project explores automated cyberbullying detection in Somali text, with an emphasis on comparing traditional text analysis techniques, deep learning models, and transformer-based approaches.

The findings may support future research and the development of tools for promoting safer online communication in Somali-speaking communities.

## Research Focus

This project contributes to the growing field of low-resource language processing by investigating how NLP and modern language models can be applied to Somali cyberbullying detection.

More details about the dataset, model architectures, experiments, and evaluation results will be documented as the project develops.
